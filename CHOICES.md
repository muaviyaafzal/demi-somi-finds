# Choices Made on Your Behalf — Demi Somi Finds

Short list of the decisions I made while building the store, so you can change any of them later.

## Stack
- **Node.js 20 + Express + better-sqlite3 (single-file SQLite).** One service serves the storefront, admin panel and API — one deploy, one public URL, no external database to configure. This is the most beginner-friendly path to a real, persistent, multi-visitor store.
- **better-sqlite3 v12** (not v11): v11 has no prebuilt binary for Node 24, so installs fall back to a native build. v12 ships prebuilt binaries for Node 20/22/24.
- **multer 2.x** (not 1.x): multer 1.x is deprecated and has known vulnerabilities that are fixed in 2.x. Same API for our usage.
- **sharp is an optional dependency**: if it installs, uploads are resized to max 1200px and compressed. If it cannot install on a host, uploads still work — files are validated and stored as-is, and the server logs a note.
- **Uploads live in `data/uploads/`** (not `public/uploads/`), so they sit next to the database. Note: on Render's free tier there is no persistent disk, so uploaded images are wiped on restart along with the database.
- **JWT stored in the browser's localStorage**: simple and reliable for a single-owner admin panel. Trade-off: a stolen token could be reused until it expires (8 hours). For a one-person store this is acceptable; the login is rate-limited and accounts lock after failed attempts.

## Store behavior
- **No cart, no checkout.** This is a showcase store: the Buy button opens the retailer's site (Amazon, Sephora, etc.) in a new tab. That matches the affiliate model — you earn commission on the retailer's site, and you never handle payments, shipping or returns.
- **Buy button appears only when a buy link exists.** A product without a link shows "Contact to order" instead. This was your requirement, built in as a rule.
- **5 demo products** with realistic US beauty prices ($16.99–$26.99) and cosmetic-safe descriptions (no medical or unproven claims). Their images are built-in SVG illustrations, so the store looks finished with zero external images.
- **Social links start empty** and are editable only from the admin panel. Empty links show as dimmed icons.
- **No contact form backend.** The Contact section shows your email (mailto link) and social icons — a form would need email delivery setup, which is out of scope for this build.
- **Dark mode toggle included** (same soft palette, gently darkened). It remembers your choice per visitor.

## Design
- **Fonts: Fraunces** (elegant serif for headings) + **Inter** (clean sans for body) from Google Fonts.
- **Palette:** soft lavender `#8E7CC3`–`#B8A9E0`, sage `#A8C5A0`, warm terracotta/coral accent, blush pink highlight, warm cream background `#FAF6F1`, soft charcoal text (never pure black).
- **Motion:** scroll reveals, hero parallax, the product hover-highlight (hovered card lifts and glows while the others dim), magnetic buttons, custom cursor with a "View" label, scroll progress bar, and a skippable intro under 2 seconds. All motion respects `prefers-reduced-motion` and is disabled on touch devices.

## Hosting
- **Render (free tier) is the recommended host**, with `render.yaml` creating the free web service. Honest limits: the free service sleeps after ~15 minutes idle (first visit can take up to a minute to wake), and the free tier does NOT allow persistent disks — so the database and uploads reset on every restart/redeploy (the 5 demo products always come back via the seed). For permanent storage, upgrade to Starter (~$7/month) and add a disk.
- **JWT_SECRET is generated by Render** via the blueprint, so admin sessions survive restarts there. Locally, if you do not set `JWT_SECRET`, the server generates a random one each start and warns you (admins get logged out on restart).
- **The server auto-seeds on startup** when the database is empty. This matters on Render's free tier: after a restart the database file is gone, so the runtime seed guarantees the store always starts again with the demo products and a demo admin.
- **Sitemap uses a placeholder domain** (`https://demi-somi-finds.example.com`) — replace it with your real Render URL after deploying.
